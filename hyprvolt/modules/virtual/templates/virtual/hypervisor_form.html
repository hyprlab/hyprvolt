{# The Hypervisor section in a server's or a NAS's form: Runs a hypervisor, ticked, makes the hypervisor record running on it, with its platform and the address it is managed at; unticked deletes it, asked first, or says what still runs on it instead. #}
A hypervisor record of the same name, running on this {{ kind }}, in Hypervisors, which virtual machines can choose as their host. Its management address is where its web interface is; this {{ kind }}'s own IP addresses are then its iDRAC, iLO or IPMI, if it has one.
